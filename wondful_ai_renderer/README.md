# Wondful AI Renderer · 双流程测试版

构建标识：`two-workflows-ui-r4`。这是流程重构测试构建，不是新正式版本。
插件注册版本暂保留 `1.2.4`；构建标识可在顶部连接区的悬停说明中核对。

## 环境参考渲染

车模与当前相机 → 环境参考 → 需求与提示词 → 生成效果图。
相机、车辆形体与构图由 Blender 决定；环境图负责场景气氛、材质、光照与反射。
不需要生成粗模，不会因场景中残留旧粗模而自动切换参考相机或多视角列表。
捕获时临时排除带所有权标记的复刻粗模，成功或异常后恢复可见性。
手动环境体块仍可在高级设置中使用。

## 参考图复刻

目标图与车模 → 生成相机与粗模 → 预览与调整 → 按当前场景渲染。
目标图使用独立输入，不再自动回退为环境参考图第一张。
生成粗模后可直接预览、调整或渲染，不再需要“已检查”勾选；必填文件和来源由后台自动校验。
修改相机或粗模后点“刷新当前预览”，不会重新调用 AI 分析或覆盖调整。
每次生成粗模自动创建带编号的新集合与独立参考相机，旧集合、几何、材质与手动改动不删除；成功后旧版自动隐藏，仍可在大纲视图查看或重新启用。
目标图原始内容与粗模记录不一致时会阻止生图，避免旧场景搭配新目标。
“目标 / 粗模”对比在尚无最终成片时即可打开。两图需使用相同画幅比例。

## 提示词与结果

两种模式分别保存提示词草稿。完整提示词优先；留空时使用一句话需求。
AI 润色为可选按钮，默认直接按当前内容生成；高级设置可重新开启自动润色。
两种模式的产品身份参考均为必填；身份图只辅助造型，不应带入另一张产品图的原有棚拍高光。
输出质量、目标长边、目录与张数在主流程可见；旧高级功能保留。
多视角是参考图复刻的进阶能力，须显式开启；普通环境渲染始终使用当前活动相机。

## 界面与按意见修改

主面板只保留标题、输入、操作和状态，解释移到按钮或问号的悬停提示。
产品、环境、目标、人物图片共用卡片：标题、缩略预览、文件名、选择/替换、粘贴/移除、参考重点。
建筑参考、三视图和多视角主图共用同一预览组件和输入样式。
在预览下方填写修改意见，点“按意见修改”；这一操作需要 Codex 登录和在线分析。
仅调整插件拥有的粗模和相机，不修改车身网格或材质。支持体块移动/旋转/缩放、显隐、现有曲带调整和简单方体增加。
可撤销本次会话最后一次调整；已有后续手动编辑时不会覆盖。无法处理的要求明确列出，不冒充已完成。
无效返回不执行，应用或预览失败时恢复调整前状态。含手动修改器、约束、动画或跨场景共用对象时会拒绝自动修改。

## Blender 侧栏与粗模历史优化（UI-r4）

- 顶部工作模式使用两个有文字的切换按钮，避免 Blender 原生枚举在窄侧栏显示成无字色带。
- 产品、环境、目标与高级参考图的缩略图不再使用大方形黑底留白：宽图采用两块无缝方形裁切缩略图，三视图宽图可采用三块缩略图；点击放大按钮可查看未裁剪原图。图片文件的读取和缩略图生成由延迟任务完成，不阻塞界面绘制。
- 粗模设置采用同一行的“匹配相机 / 自动校正”开关，“深度测量 / 场景补全”移入可折叠的更多选项。
- 粗模生成期间显示阶段、耗时和估算进度条；“取消生成”可点击，输入控件暂时锁定。
- **每次构建独立的编号版本**：`Wondful 场景粗模 · 001`、`002` 等，生成的参考相机与场景材质归属各自版本；旧版本隐藏但绝不自动删除。
- 深度载体与推测补全也归入当前粗模版本，后续构建不再全局清理旧版本；多视角只读取活动版本。
- 旧工程没有 r4 集合指针时，按可见的现存粗模识别当前版本；带编号版本可保留作为历史。

## 参考图复刻 · 高对比几何灯架（geometry-r3）

针对黑色汽车影棚中的多层发光三角/V 型门架，粗模新增 `light_frames` 结构类型：
将各组明亮的开放式灯架分开建成真实、有厚度、可编辑的 3D 梁体，正面发光、侧面较暗；
保留三角内部黑色留空，不再用实心建筑墙或连续曲带代替直线灯带。
支持画幅外的 V 形顶点、不同的层深和水平红色灯带。
图像直线检测可向分析模型提供亮梁候选及双梁推算的画外 V 顶点；
只有在极暗室内、两根长亮梁强匹配、AI 未输出对应 V 梁且没有宽大曲带的情况下，
才会保守补建一个标记“待复核”的外层灯架。车身反光不直接视为建筑。
生成后仍需用目标/粗模对比并按意见修正。照片无法唯一推断真实深度和隐藏结构。
黑色镜面影棚地坪按深色、低粗糙度处理；非影棚场景不受影响。

构建说明和原生待执行验收：`docs/testing/STUDIO_LIGHT_FRAMES_R3.md`（源代码证据包中）。

## 安装与旧工程

先保存当前 .blend 并保留旧安装包。停用旧插件，使用 Blender 的“从磁盘安装”安装新 ZIP，重启 Blender。
不要把新旧同名插件复制到多个目录同时启用。主面板顶部有明确的“环境渲染 / 参考图复刻”文字按钮；说明文案改为悬停显示。
旧工程缺少工作模式字段时默认进入环境参考渲染，不根据现存粗模猜测模式。
旧粗模缺少本版来源记录：切换到参考图复刻，明确选择目标图后重新构建一次，再预览和渲染。
模式切换本身不改相机、几何、材质、灯光或可见性，也不删除旧粗模。
注册版本未升级，本测试构建不要用“一键更新”替换，否则可能回到现有正式包。
