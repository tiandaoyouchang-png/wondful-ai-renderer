# Wondful AI Renderer · 双流程测试版

构建标识：`two-workflows-r1`。这是流程重构测试构建，不是新正式版本。
插件注册版本暂保留 `1.2.4`；请在面板顶部核对构建标识。

## 环境参考渲染

车模与当前相机 → 环境参考 → 需求与提示词 → 生成效果图。
相机、车辆形体与构图由 Blender 决定；环境图负责场景气氛、材质、光照与反射。
不需要生成粗模，不会因场景中残留旧粗模而自动切换参考相机或多视角列表。
捕获时临时排除带所有权标记的复刻粗模，成功或异常后恢复可见性。
手动环境体块仍可在高级设置中使用。

## 参考图复刻

目标图与车模 → 生成相机与粗模 → 预览与调整 → 按当前场景渲染。
目标图使用独立输入，不再自动回退为环境参考图第一张。
生成粗模后停止在检查阶段；检查相机、主体位置、连续曲面与遮挡后，勾选确认再渲染。
修改相机或粗模后点“刷新当前预览”，不会重新调用 AI 分析或覆盖调整。
重复生成粗模会请求确认；现有粗模会被新构建替换，手动改动请先另存工程。
目标图原始内容与粗模记录不一致时会阻止生图，避免旧场景搭配新目标。
“目标 / 粗模”对比在尚无最终成片时即可打开。两图需使用相同画幅比例。

## 提示词与结果

两种模式分别保存提示词草稿。完整提示词优先；留空时使用一句话需求。
AI 润色为可选按钮，默认直接按当前内容生成；高级设置可重新开启自动润色。
车辆身份参考只辅助造型，不应带入另一张产品图的原有棚拍高光。
输出质量、目标长边、目录与张数在主流程可见；旧高级功能保留。
多视角是参考图复刻的进阶能力，须显式开启；普通环境渲染始终使用当前活动相机。

## 安装与旧工程

先保存当前 .blend 并保留旧安装包。停用旧插件，使用 Blender 的“从磁盘安装”安装新 ZIP，重启 Blender。
不要把新旧同名插件复制到多个目录同时启用。主面板应显示“环境参考渲染 / 参考图复刻”和构建标识。
旧工程缺少工作模式字段时默认进入环境参考渲染，不根据现存粗模猜测模式。
旧粗模缺少本版来源记录：切换到参考图复刻，明确选择目标图后重新构建一次，再检查确认。
模式切换本身不改相机、几何、材质、灯光或可见性，也不删除旧粗模。
注册版本未升级，本测试构建不要用“一键更新”替换，否则可能回到现有正式包。

## 验证边界

已运行离线回归测试和 Python 编译检查。离线测试模拟 bpy / RNA / UILayout；不是 Blender 原生交互验收。
本轮没有新的真实 YU7 原生渲染或在线 AI 出图，也未验证 Mac / Windows 的安装与显示。
不能据此承诺相机匹配、模型细节和光照终稿已全面通过。
正式发布前仍需使用真实工程完成两条流程的 Blender 实机及在线出图回归。
