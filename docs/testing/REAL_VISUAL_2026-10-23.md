# 自建场景真实出图验证 · 2026-10-23

结论：真实图片已生成，但整体视觉验收未通过。不能沿用“流程通过”作为渲染效果通过。

## 环境和执行边界

- 自建无品牌简化测试车，包含银白车漆、深色玻璃、五条黑辐轮毂、8 m 土路、0.32 m 宽 / 0.12 m 高路沿、砂石路肩和低墙。
- Blender 4.3.2 / Linux / Cycles CPU，1280×720 控制图、640×360 几何工作通道；三台原生相机为主视角、+72°、+216°。
- 真实生成 4 张图片：主视角、48df483 基线的 216°、本次高度分段修复的 216°、多参考图实验的 216°。
- 白模、材质、遮罩、Position / Normal、细节与 Material-ID 通道由 Blender 实际渲染。
- 投影、地面分带、提示词构建、细节回贴和评分调用插件真实代码。
- 生图通过本会话内置 ImageGen 工具手动衔接，不是插件 Codex 直连账号返回；没有验证插件登录、计费或整条线上服务链路。模型具体版本、随机种子不由本次工具暴露。

## 真实输入暴露并修正的问题

基线在真实主视角生成图上漏检凸起路沿。分段主要依赖颜色，生成图的材质/阴影边界与几何边界不完全重合；相近颜色会把凸起带并入路面。

本次让实测高度跳变参与切分，阻止跨高度边界合并，并保留至少两个工作采样格宽的真实凸起窄带；有两侧高度证据时，即便颜色不明显也可识别为路沿。

在本场景中，基线没有 curb；修复后识别到约 0.11 m 的高度（建模值 0.12 m）。宽度按 0.1 m 工作采样格得到 0.4 m（建模值 0.32 m），仍存在边界量化误差。这是检出改善，不是尺寸完全准确。

新增 6 项回归，覆盖同色凸起、窄凸起、几何分类、平面、缓坡与短缺失采样。
全量结果：750 项，737 通过、13 跳过、0 失败；编译、undefined-name 与 diff 空白检查通过。

## 视觉结果

| 项目 | 观察 | 判断 |
|---|---|---|
| 主视角生成 | 主车布局和主要轮廓接近原生控制图；材质细节和反射形成了真实生成结果 | 部分符合 |
| 基线 216° | 轮毂被替换成细辐轮毂；路沿变浅；远处道路出现抬升/堤道观感 | 未通过 |
| 高度分段修复 216° | 仍能见到路面/路沿/路肩；轮毂设计仍被改写，远景和地面观感有偏差 | 未通过 |
| 插件细节回贴 | 基线回贴被放弃；修复样本回贴 1 处，但轮毂身份仍未可靠恢复 | 不足以验收 |
| 多参考图实验 | 加入同机位原生材质图与真实主视角图后，五辐轮毂、深色路沿和水平地面观感更接近目标 | 有价值，仍未通过 |
| 多参考图实验的构图 | 车身在画面中的大小/位置仍有变化 | 构图锁定仍需加强 |

插件评分在两个原始 216° 样本上分别给出约 2 px / 0 px 位移、3.6 px / 2.2 px 轮廓、ΔE 16 / 7；这些低误差并未可靠拒绝轮毂身份错误，因此评分目前也不是充分的验收门槛。

这是每种设置一次的探索性对照，无固定种子；各生成图差异不能全部归因于代码改动。多参考图实验同时更换了提示词和输入数量，只能作为下一步方案证据，未接入插件默认请求。

## 剩余问题和下一步

1. 轮毂等零件身份需要独立判定，当前整体边缘/颜色评分会漏报。
2. 几何与材质多参考输入值得继续测试，但不能以牺牲相机构图和产品占比为代价。
3. 路沿边界还需要亚采样格的几何测量，避免窄带宽度被 0.1 m 栅格放大。
4. 可疑的深色平面条带仍未被可靠排除，不能自动当作真实材质分区向远处延伸。
5. 自建简化车不代表 DEEPAL 等量产车型身份已经验证。尚需真实生产资产的多角度复核。
6. 本次未验证真实插件账号、全局计费次数上限或 Win/mac/GPU。

本次所有输入、原始生成图片、回贴图片、提示词、测量数据、Blender 工程和构建脚本随交付包保存。不将这轮标为稳定版效果验收通过。
