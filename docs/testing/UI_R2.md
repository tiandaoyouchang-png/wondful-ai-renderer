## 修改意见的执行边界

输入修改意见后，使用目标图、当前原生预览、产品身份参考和现有场景快照进行一次在线分析。目前需要 Codex 登录。
返回值只允许严格 JSON 调整计划，不执行模型生成的代码或命令。
支持相机位置/角度/焦距、已有体块变换与显隐、已有曲带的截面调整、简单方体添加。
车身网格、材质、产品位置不在可修改列表中。车漆写实重打光等不属于粗模操作的要求会列入未处理项。
应用前检查场景、图片文件和几何指纹。等待期间的手动改动会阻止过期结果应用。
应用或预览失败会回退，保留修改意见。支持当前会话最后一次撤销，不是持久化多步历史。
粗模有手动修改器、动画、约束、形态键或跨场景共用时，保守拒绝自动修改。

## 同时修复

- 刷新预览不再误触发目标图变更，不再使提示词草稿失效。
- 环境图的“添加”真正追加；卡片内粘贴只替换该卡片。
- 新图读取失败不清空旧卡片；失效索引不误删最后一张。
- 同一路径替换目标图也会失效旧预览；缩略图按文件变更刷新。
- 打包在 .blend 里的图片从真实像素生成预览，不覆写源图；预览缓存上限 48 项。
- 任务运行时禁用修改输入，保留进度和取消入口。
- 目标图对比不再显示旧成片的车辆构图评分，不再使用产品轮廓模式。
- 修复连续调整中上一份撤销清理可能删除下一份网格备份的风险。
