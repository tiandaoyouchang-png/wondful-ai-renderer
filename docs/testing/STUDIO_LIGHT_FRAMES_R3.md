# Wondful · 参考图复刻中的发光三角影棚粗模（geometry-r3）

构建标识 `two-workflows-geometry-r3`，插件原注册版本仍为 `1.2.4`。
只更新“参考图复刻”中的场景分析、场景粗模与粗模修改；“环境参考渲染”流程保留。

## 这次参考图为什么难识别

参考图约 1456×816。三组可见的 V 型灯梁叠在黑色负空间上；最外层 V 顶在画幅上方之外，
两侧有相当厚度的白色宽梁，中层窄梁、内层很细，后景还有低位水平红光线。
反光地面出现多组长条高光；银色车辆反光容易被误识别为建筑。
旧的 JSON 模型只有 primitive/ribbon，难以同时表达“未闭合的多段灯梁、外缘、前后层次、白色发光面”。

## 变更内容

- `studio_frames.py`：严格 `light_frames` 结构类型、屏幕归一化坐标、厚度、深度、发光颜色和材料，闭合 manifold 真 3D 梁网格。
- `studio_edge_guides.py`：纯 numpy 长亮梁候选检测、两条外层直线向画幅外求交点。仅供 AI 分析参考；强置信的暗室/双亮梁/缺 V/无曲带情形，可补救一个 **待复核** 的外层门架。
- `scene_blockout.py`：AI 结构化 schema、提示词、修订优先级、材质注记。
- `scene_blockout_build.py`：从目标图屏幕锚点和相机射线生成可编辑 3D 梁；独立灯面与边框材质，地面接触深度检查；暗室中的镜面地面。
- `operators.py`：首轮上传图片时提供亮线候选、画外 V 顶，保守补建遗漏；用灯架与实图亮度一致性指标替代黑背景的天空 IoU。
- `replica_revision.py` / `replica_revision_blender.py`：用户在“预览与调整”输入意见后可调整已有灯架的端点、宽度、深度和亮度，遵循原有事务/回滚/撤销保护。
- 旧工程和旧 JSON 若不含 `light_frames`，继续正常使用。

## 使用步骤

1. 安装插件测试包并重启 Blender，打开你的车辆工程（请先另存副本），选择 **参考图复刻**。
2. 指定有效产品身份参考图和自己的车模集合，选择这张三角灯架影棚目标图。
3. 运行 **生成相机与粗模**，在 **预览与调整** 对比外层大 V、中层 V、后层窄光带、水平红灯带和负空间。
4. 如果灯梁顶点、梁宽或前后层级有误，在修改意见中写“外层 V 顶点延长至画幅上方 20%，中层向右，主车不要动”等，再点击“按意见修改”。
5. 确认粗模结构和相机后再渲染；如来源哈希改变应重新选择/构建，防止错用旧图。

## 真实图片离线校核（不等于在线 AI 自动识别）

- 图像候选：本参考图被候选检测器提取出 3 条长亮线，其中两条属于外侧宽梁；可推算外层 V 顶屏幕坐标约 `(0.581,-0.247)`。
- 人工手工标注的 4 个灯架结构：外层宽 V、中层窄 V、后层蓝白 V、后景水平红灯带。
- 2D→3D→2D 投影锚点最大误差约 `0.104 px`（数学测试，不证明 3D 深度正确）。
- 帧匹配 `F≈0.730`、精度 `≈0.681`、召回 `≈0.818`，**这些是人工给定结构和实际照片的像素对齐分数，不是 AI 自动识别准确率**。
- 检测到的图像候选和完整结构示例保存在 `diagnostics/` 和 `fixtures/`。

## Blender 实机待验收

在有 Blender 的环境中，从源代码根目录调用：

```bash
blender --background --factory-startup --python-exit-code 1 \
  --python tools/native_studio_frames_smoke.py -- /path/to/source /path/to/empty-output
```

脚本只在**全新后台 Blender 进程**使用手工标注的目标进行 4 组发光梁 mesh / 材质 / 相机 / Cycles 截图检查，不修改用户工程，不调用在线 API。
