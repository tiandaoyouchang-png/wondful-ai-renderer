## 本次实现

| 区域 | 行为 |
| --- | --- |
| 工作模式 | 显式 ENVIRONMENT / REFERENCE，保存到工程；旧工程默认 ENVIRONMENT |
| 环境参考渲染 | 当前相机与真实车模；环境图只负责环境外观；不触发粗模或复刻多视角计划 |
| 参考图复刻 | 独立目标图；生成相机/粗模；提供含车模预览；人工确认；再进入共用渲染 |
| 引用隔离 | 两模式使用不同参考路径，普通模式不读旧粗模来源图、季节锁定和地面分析 |
| 捕获隔离 | 仅临时隐藏带生成所有权标记的粗模/补全几何；不隐藏产品、相机、灯光；异常与嵌套捕获恢复 |
| 提示词 | 模式分别保存草稿；完整提示词优先；润色默认关闭；旧 AI 文案与新参考/新需求不再混用 |
| 校验 | 来源副本 SHA、原目标 SHA、实际参与渲染的粗模来源和人工确认都在在线请求之前检查 |
| 预览 | 初次构建无自动校正时仍创建预览；刷新只使用当前相机与现有粗模；失败不冒充预览成功 |
| 对比 | 底图/成片、目标/粗模、目标/成片；目标对比不误用产品轮廓指标 |
| 场景保护 | 模式切换不动场景；重复粗模构建从界面调用时提示确认；多视角必须显式开启 |
| 界面 | 顶部两入口，连接状态紧凑展示，四段任务流程，输出设置前置，旧高级功能保留 |

车辆保真、细节修复、渲染服务与结果输出仍走原有共用核心，本次没有新增一套不一致的生成实现。
“环境参考渲染”是用户定义的 1.0 正式能力方向，不是把代码版本号回退为 1.0。
注册版本仍为 1.2.4，构建标识为 two-workflows-r1，不修改正式发布清单。

## 发布前实机检查

1. 安装 ZIP，重启，确认顶部 two-workflows-r1；打开旧 YU7 工程，默认环境模式，原相机不变。
2. 现存复刻粗模下运行普通环境渲染：底图排除旧粗模，结束与异常后可见性恢复；车辆、手动环境和当前机位保留。
3. 切换两模式，验证手写草稿往返保存，环境参考与复刻目标互不覆盖。
4. 参考图复刻：独立选择目标，生成粗模；即使自动校正关闭也有含车模预览；未勾选检查不能发起出图。
5. 手动改机位/粗模，刷新预览，不重新分析；检查“目标 / 粗模”工作区；确认后生图。
6. 替换同一路径的目标文件或换用其他粗模，确认在在线调用之前被来源校验拦住。
7. 真正出图后分别验收相机、车型身份、场景结构与车身受光，不只看外轮廓分数。
