# Wondful AI Renderer · UI-r4 设计与功能验收

构建标识：`two-workflows-ui-r4`。插件注册版本仍为 `1.2.4`；本包不是正式发行版。
源码基线：`geometry-r3` 已验证打包源码；GitHub 修复分支截至此前提交 `ded000622168f6d7333460ce232ca2a24516787e`。本次未执行 GitHub 推送。

## 截图问题对应修复

| 原有问题 | UI-r4 的处理 |
| --- | --- |
| 顶部工作模式是无字色条 | 用“环境渲染 / 参考图复刻”两枚显式带字按钮，新增“工作模式”标题；选中态下压。
| 图片框巨大留白 | 不再将宽图缩在单个正方形 icon 中；原生横幅由 2 块连续封面式缩略图构成。超宽三视图采用 3 块。点击放大可查看未裁剪图。
| 原来 4 个独立纵向勾选显得拥挤 | 主要 2 个选项同一行按钮，另外 2 个折叠在“更多选项”内，标题、控件高度、间距统一。
| 生成粗模没有明显进度 | 阶段名称、已用时间、估算百分比进度条、取消按钮统一出现在当前工作步骤。生成期间输入禁用，但取消仍可用。
| 再次生成删除旧场景 | 每次成功构建一个新集合 `Wondful 场景粗模 · NNN`；新相机、几何、材质、分析记录独立；旧版本隐藏但保留，不再调用隐式删除代码。
| 深度细节/补全会偷偷删旧版本 | 每个细节/推测集合都是版本子集合，移除了正常生成路径中的全局删除；多视角只读取当前版本的相关信息。

## 保护规则

- `scene_blockout_build.build()` 不调用旧版 `remove_existing()`；旧函数只作为显式维护接口保留。
- 生成失败隐藏部分生成的集合、恢复原相机及之前的活动版本；不覆盖旧版本已有网格和材质。
- 新版本生成成功后旧版本只隐藏；旧版生成的相机、材质、分析 Text 均按版本区分；引用用户车模与身份参考逻辑不变。
- 保留参考图复刻的目标/粗模/成片对比、修改意见与撤销逻辑；环境渲染保留用户当前相机。
- 图片的文件读写、统计及采样在后台计时器中执行，面板 `draw()` 不进行解码或 I/O；缩略图缓存最多 48 个。预览裁切仅影响侧栏缩略图，原始图片未修改。

## 测试与限制

**离线**运行 `python -m unittest discover -s tests -q`：151 项测试，0 失败、0 跳过；包含本轮新加的 14 项版本管理、UI 布局与预览算法专项测试。
`python -m compileall -q wondful_ai_renderer tests` 编译通过。包内文件 SHA-256 在清单中列出。

尚未进行真实 Blender 原生 UI 截图验收；没有 Blender 二进制、`bpy` 或真实界面。因此无法承诺在 macOS Retina 缩放、实际窄 N 面板、已打包图片图标缓存、Cycles 光照、多视角 Blender 链路均已通过。也未调用在线 AI 或重新渲染车模。测试中用于判断按钮显示和进度的 `UILayout` 是严格的离线替身，不是实机截图。

建议实机验收：

1. Blender 4.3+ 安装 ZIP，重启，打开 N 面板，确认 240–380px 宽度下顶部两个按钮文字完整，主图缩略图填满卡片横向区域。
2. 切到“参考图复刻”，检查两个开关排在同一行，“更多选项”可展开其他两项。
3. 点击生成，确认进度条、阶段提示与取消按钮工作；输入按钮被锁定。
4. 连续生成两次，对照大纲结构：旧 `001` 集合及子对象、相机、材质、分析文本均存在；`002` 被激活，旧版隐藏。
5. 运行失败/取消时上一版可恢复，现有真实车模未改动；手动保存工程并重开后历史集合仍存在。
6. 使用三视图/超宽产品身份参考、16:9 环境图、复刻目标图、高级建筑参考图检查预览与放大，确认没有大块空白也未拉伸。
7. 在新版本预览与多视角生成中检查不会混入旧版深度细节、推测建筑或重复地形。
